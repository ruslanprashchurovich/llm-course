# llm-cli — терминальный помощник на локальной LLM

Финальный проект модуля 1 курса «LLM для Python-разработчиков»: утилита командной строки поверх Ollama, собранная из всего, что пройдено в уроках 1.1–1.7. Один файл, ~300 строк, ноль облачных зависимостей.

## Требования

- Запущенная Ollama с моделью `qwen2.5:3b` (урок 1.5)
- Python 3.10+ и пакеты:

```bash
pip install openai httpx pydantic
```

## Команды

```bash
# проверить, что всё живо: сервер -> модель -> генерация
python llm_cli.py health

# разовый вопрос (ответ печатается стримингом)
python llm_cli.py ask "Что такое GIL в Python?"
python llm_cli.py ask "Зачем нужен Redis?" -t 0.3 --no-stream --stats

# краткое содержание файла или stdin
python llm_cli.py summarize README.md
python llm_cli.py summarize notes.txt -s 5
type app.log | python llm_cli.py summarize        # Windows (в bash — cat)

# категория обращения в поддержку (few-shot + JSON + Pydantic)
python llm_cli.py classify "Не приходит письмо для сброса пароля"
python llm_cli.py classify "Списали деньги дважды" --json

# интерактивный чат с памятью (команды: /bye, /clear)
python llm_cli.py chat
```

## Конфигурация

Всё через переменные окружения — как DSN базы данных (урок 1.4):

| переменная | по умолчанию | зачем |
|---|---|---|
| `LLM_BASE_URL` | `http://localhost:11434/v1` | адрес OpenAI-совместимого API |
| `LLM_MODEL` | `qwen2.5:3b` | модель |
| `LLM_API_KEY` | `ollama` | ключ (локально не проверяется) |
| `LLM_TIMEOUT_S` | `120` | таймаут запроса |

Смена провайдера — правка окружения, не кода: укажите `LLM_BASE_URL` облачного API и его ключ, и утилита продолжит работать (урок 1.3).

## Какие уроки где работают

| место в коде | урок |
|---|---|
| конфигурация из окружения, `max_retries`, дружелюбная ошибка соединения | 1.4 |
| `stream_answer` — печать токенов по мере генерации | 1.4 |
| `cmd_health` — трёхуровневая проверка | 1.5 |
| `MAX_INPUT_CHARS` — защита от тихой обрезки контекста | 1.1, 1.5 |
| разделители `<text>` вокруг данных | 1.2 |
| `FEW_SHOT_BLOCK` — примеры блоком в системном промпте | 1.7 |
| `TicketRoute` + повтор с текстом ошибки валидации | 1.2 |
| `MAX_HISTORY` — обрезка истории чата | 1.1, 1.6 |

## Идеи для развития (задания урока 1.8)

1. Команда `commit`: `git diff --staged | python llm_cli.py commit` → сообщение коммита.
2. Глобальный `--stats` со стоимостью запроса «как если бы это было облако» (цены — урок 1.3).
3. Команда `translate` с few-shot примерами вашего глоссария.
4. Персистентная история чата в `~/.llm_history.json` — диалог переживает перезапуск.
5. Упаковка в pip-пакет с entry point, чтобы писать просто `llm ask "..."`.
