# Модуль 9. Глоссарий и закрепление по всему курсу

Финальный модуль курса «LLM для Python-разработчиков: от RAG до агентов» —
справочник и самопроверка. Новых концепций здесь нет: только весь курс,
разложенный по полочкам.

## Состав модуля

| Файл | Что это |
|---|---|
| [`GLOSSARY.md`](GLOSSARY.md) | Глоссарий курса: **115 терминов** с определениями, ссылками на уроки и перекрёстными «см. также». Русский и латинский алфавитные блоки с указателем. |
| [`test-1-foundations.md`](test-1-foundations.md) | **Итоговый тест 1** (32 вопроса): основы LLM, эмбеддинги, векторные БД, базовый RAG — модули 1–3. Ответы под спойлерами. |
| `02-test-1.ipynb` | Он же — интерактивно: впишите ответы в `ANSWERS`, ячейка проверки посчитает результат и объяснит ошибки. |
| [`test-2-production.md`](test-2-production.md) | **Итоговый тест 2** (33 вопроса): продвинутый RAG, локальные LLM, дообучение, агенты, продакшен — модули 4–8. |
| `03-test-2.ipynb` | Интерактивная версия теста 2. |

## Как пользоваться

- **Глоссарий** — как справочник: забыли термин по ходу работы — Ctrl+F.
  Каждая статья ссылается на урок, где термин разобран с живыми примерами.
- **Тесты** — после прохождения соответствующих модулей. Все вопросы
  **сценарные и оригинальные**: не «что такое X», а «у вас произошло Y —
  почему и что делать». Правильный ответ без понимания угадывается плохо —
  так и задумано.
- В ноутбуках ключ ответов закодирован (base64), чтобы глаз не цеплялся
  за спойлеры, — но это самопроверка: судья здесь вы.

Шкала в конце каждого теста подскажет, какие модули стоит перечитать —
пояснения к ошибкам ссылаются на конкретные уроки.
