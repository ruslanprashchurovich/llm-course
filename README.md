# LLM для Python-разработчиков: от RAG до агентов

Практический курс-самоучитель для бэкенд-разработчика, который хочет строить
системы на больших языковых моделях — руками, локально и бесплатно. Девять
модулей: от «что такое токен» до задеплоенного AI-ассистента с поиском,
цитированием, метриками и тестами.

## Философия курса

- **Всё живьём.** Почти каждая ячейка каждого урока исполнена по-настоящему:
  числа в текстах — из реальных прогонов, включая неудачные (они помечены и
  разобраны — это лучший материал). Где результат зависит от железа, даны
  диапазоны и оговорки.
- **Всё бесплатно и локально.** Ollama + модели с открытыми весами (qwen2.5),
  Qdrant в Docker, sentence-transformers на CPU, бесплатный Colab для
  дообучения. Платные API не нужны нигде; ваши данные не покидают машину.
- **Инженерия, а не магия.** Каждому приёму — измеримая причина: сначала eval,
  потом улучшение. Сквозная лестница курса: промпт → few-shot → RAG → жёсткие
  форматы → дообучение → команды агентов. Подъём на ступень — только по
  показаниям.
- **Аналогии для бэкендера.** Векторная БД объясняется через индексы SQL,
  Modelfile — через Dockerfile, чанкинг — через нормализацию данных.

## Что понадобится

- **Машина:** Windows 11 / Linux / macOS, Python 3.13 (подойдёт 3.11+),
  16 ГБ RAM комфортно (минимум 8), ~15 ГБ диска под модели. **GPU не нужен**
  (с ним быстрее, и это честно оговаривается в замерах).
- **Ollama** с моделью `qwen2.5:3b` (~2 ГБ) — рабочая лошадка курса с модуля 1.
- **Docker** — для Qdrant (модули 2–4, 8) и желающих собрать compose-варианты.
- **Google-аккаунт** — один раз, для бесплатного Colab в модуле 6.
- Остальное ставится по `requirements.txt` конкретного модуля.

## Как проходить

1. Модули идут по порядку и опираются друг на друга; внутри модуля уроки —
   тоже по порядку. Ориентир по времени — в [STUDY_PLAN.md](STUDY_PLAN.md).
2. В каждом модуле: `README.md` (цели, установка, честные ориентиры из прогонов,
   FAQ), пронумерованные ноутбуки уроков и `requirements.txt`.
3. Ячейки с внешними зависимостями (Ollama, Qdrant, модели) проверяют
   доступность и вежливо пропускаются с подсказкой — но ценность курса в живых
   запусках: поднимите зависимости и прогоните.
4. Финальный урок каждого модуля — закрепление: карта модуля, сводный квиз
   и практика **без решений** (это ваши проекты). У остальных уроков упражнения
   идут с разборами.

## Соглашения курса

- `127.0.0.1` вместо `localhost` во всех адресах — на Windows это экономит
  ~2 секунды на соединение (замер в уроке 3.2).
- HTTP — через `httpx`; таймауты и ретраи всегда явные (матрица: connect и
  503 — повторяем, ReadTimeout на генерации — никогда).
- Числа производительности — диапазоны с оговорками: GPU-недетерминизм и
  троттлинг реальны.
- Легенды сквозные: база знаний компании «Векторика» (модули 2–4, 8) и хостинг
  «Пингвин.Хост» 🐧 (модули 6–7). Все данные синтетические.
