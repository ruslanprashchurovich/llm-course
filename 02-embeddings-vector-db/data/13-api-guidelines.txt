Стандарты проектирования API

Все внутренние сервисы предоставляют REST API по спецификации OpenAPI 3.1. Схема генерируется из кода (FastAPI) и публикуется в общем каталоге API. Ломающие изменения без новой версии запрещены.

Версионирование — через префикс пути: /api/v1/, /api/v2/. Старая версия поддерживается минимум 6 месяцев после выпуска новой. Устаревшие поля помечаются deprecated в схеме и в заголовке ответа Sunset указывается дата отключения.

Формат ошибок единый: JSON с полями code (машиночитаемый код), message (человекочитаемое описание) и request_id для поиска в логах. Коды 4xx — ошибка клиента, 5xx — наша.

Пагинация — курсорная (параметры cursor и limit, максимум 100 элементов). Все запросы идемпотентны где возможно; для POST-операций с деньгами обязателен заголовок Idempotency-Key.
