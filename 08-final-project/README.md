# Модуль 8. Финальный проект: Docs Assistant

Часть курса «LLM для Python-разработчиков: от RAG до агентов». Главный модуль:
здесь курс собирается в один работающий продукт — **AI-ассистент по внутренней
документации** компании «Векторика».

Модуль устроен иначе, чем предыдущие: рядом лежит папка **[`project/`](project/)** —
полностью рабочее FastAPI-приложение (поиск, генерация с цитированием,
SSE-стриминг, история, health-пробы, метрики, 73 теста, Docker). Шесть уроков —
это разбор проекта слой за слоем, с живыми запусками.

## Что понадобится

- Python 3.13, пакеты из `project/requirements.txt`.
- Запущенный **Qdrant** (`docker compose up -d` — подойдёт контейнер модуля 2,
  порты общие).
- **Ollama** с `qwen2.5:3b` (для уроков 4–5; урок 3 работает и без неё).
- Модели эмбеддингов (e5-small, ~120 МБ) и reranker'а (~500 МБ) скачаются при
  первом запуске; reranker можно выключить: `APP_RERANKER_ENABLED=false`.

## Быстрый старт проекта

```powershell
cd project
python -m venv .venv; .\.venv\Scripts\Activate.ps1   # или используйте общее окружение курса
pip install -r requirements.txt
python scripts/index_docs.py          # 12 документов -> Qdrant
uvicorn app.main:app --port 8000
```

Проверка: `Invoke-RestMethod http://127.0.0.1:8000/ready`. Примеры запросов —
в [project/README.md](project/README.md).

## Честные ориентиры из живых прогонов (ноутбук фиксирует свои)

- Индексация: 12 документов → 61 чанк, эмбеддинги за ~1.5 с.
- Поиск: ~40 мс без reranker, ~590 мс с ним (CPU cross-encoder, 20 кандидатов).
- Генерация: 1–3 с тёплая; первый запрос после старта ~8 с (холодная загрузка
  модели в Ollama — урок 5.3).
- Стриминг: первый токен через ~0.9 с.
- Тесты: 73 passed за ~1 с без внешних зависимостей.
- Окно контекста (`APP_LLM_NUM_CTX`, по умолчанию 8192) на qwen3.5:9b и RTX 5050 8 ГБ:
  4096/6144 → 100% GPU (5.5–5.6 ГБ), 8192 → 12% слоёв на CPU (6.3 ГБ);
  генерация 22–26 ток/с во всех трёх вариантах — разброс в пределах шума.

## FAQ

**Можно ли пройти модуль без Ollama?** Уроки 1, 2, 3, 5 — да (поиску LLM
не нужна; в 5-м деградация показывается как раз на выключенной Ollama).
Урок 4 (генерация) требует модель.

**docker-compose прогонялся?** Нет — честная пометка стоит в самом файле.
Сервис проверялся локальным uvicorn против локальных Qdrant и Ollama.

**Почему ассистент не мульти-агентный?** Потому что задача — один связный шаг,
а команда стоит ×3 (урок 7.1). Это осознанное решение, записанное в уроке 6.
