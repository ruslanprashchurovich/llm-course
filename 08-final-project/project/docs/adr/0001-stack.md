# ADR-0001. Стек: FastAPI + Qdrant + Ollama

Дата: 2026-08. Статус: принято.

## Контекст

Нужен внутренний ассистент по документации: поиск и ответы с цитированием,
без передачи текстов во внешние API (документация — внутренняя), бюджет — ноль.

## Решение

FastAPI (async, Pydantic-контракты, привычен команде), Qdrant как векторная БД
(отдельный сервер, payload-фильтры, снапшоты), Ollama + qwen2.5:3b как LLM-слой
(модель уже эксплуатируется, известны её пределы), sentence-transformers для
эмбеддингов на CPU.

## Альтернативы

- Облачные LLM: лучше качество, но документация покидает контур и появляется
  счёт за токены. Отвергнуто требованием приватности.
- Chroma вместо Qdrant: проще для прототипа, но нет отдельного сервера и
  прод-инструментов (снапшоты, payload-индексы). Qdrant уже стоит в проде.

## Последствия

Качество ответов ограничено 3B-моделью: обязательны grounding-промпт с
цитированием, честный отказ и низкая температура. Масштабирование LLM —
заменой модели в Ollama без изменения кода.
