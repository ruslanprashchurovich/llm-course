# ADR-0002. Эмбеддинги: intfloat/multilingual-e5-small на CPU

Дата: 2026-08. Статус: принято.

## Контекст

Документация на русском; сервису нужен многоязычный эмбеддер, работающий
на CPU с приемлемой задержкой (< 100 мс на запрос).

## Решение

`intfloat/multilingual-e5-small`: 384 измерения, ~120 МБ, сильный на русском,
хорошо изучен командой. Обязательны префиксы `query:` / `passage:` — зашиты
в EmbeddingService, чтобы никто не забыл.

## Альтернативы

- e5-large: точнее, но в 5 раз тяжелее и медленнее на CPU - не окупается
  на нашей базе (~сотни чанков).
- Эмбеддинги через Ollama: меньше зависимостей, но модель пришлось бы держать
  в памяти LLM-сервера постоянно, конкурируя с генерацией за ресурсы.

## Последствия

Размерность 384 зашита в конфиг (embedding_dim) и в коллекцию Qdrant: смена
модели эмбеддингов = переиндексация с --recreate.
