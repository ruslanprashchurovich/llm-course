# Локальное окружение разработчика

Как развернуть проект на своей машине с нуля. Ожидаемое время — меньше часа.

## Предварительные требования

Python 3.13, Docker Desktop (или Podman), git и make. На Windows работаем через
WSL2 — нативная разработка не поддерживается инфраструктурными скриптами.
Минимум 16 ГБ RAM: контейнеры окружения съедают около шести.

## Быстрый старт

Клонируйте монорепозиторий `vectorika` и выполните `make bootstrap` — команда
создаст виртуальное окружение, установит зависимости из lock-файла и поднимет
инфраструктурные контейнеры (PostgreSQL, Redis, RabbitMQ, MinIO) через
docker compose. Проверка: `make smoke` должен закончиться зелёным за пару минут.

## Зависимости

Зависимости управляются через uv и фиксируются в `uv.lock`. Добавили пакет —
закоммитьте обновлённый lock-файл в том же MR. Прямые правки `requirements*.txt`
запрещены: они генерируются из lock-файла в CI.

## Частые проблемы

Если `make bootstrap` падает на портах — проверьте, что порты 5432, 6379, 5672
и 9000 не заняты другими проектами. Если тесты не видят PostgreSQL — контейнеры
поднялись, но не прошли health-check: подождите 30 секунд и повторите. Секреты
для локальной разработки берутся из файла `.env.local`, который каждый инженер
получает при онбординге из Vault (см. документ про секреты).
