# Модуль 6. Дообучение через LoRA: стиль — в веса

Часть курса «LLM для Python-разработчиков: от RAG до агентов».

Пять модулей мы давали модели **знания** (RAG) и надёжную обвязку (мониторинг,
прокси). Этот модуль — про **поведение**: как вшить в веса модели фирменный стиль,
которого не добиться промптом. Сквозная легенда — саппорт-бот хостинга
«Пингвин.Хост» 🐧 с жёстким регламентом ответа.

Обучение идёт на **бесплатном Google Colab** (T4): свой GPU не нужен, платные
сервисы не нужны.

## Цели модуля

После прохождения вы сможете:

- Отличать задачи для fine-tuning от задач для RAG и промптинга (матрица выбора).
- Объяснить LoRA и QLoRA «на пальцах» и посчитать параметры/память для любой модели.
- Готовить датасет для чат-модели: ChatML, train/val, loss только на ответах.
- Обучать LoRA-адаптер через unsloth на Colab (15 шагов для стиля!).
- Возвращать модель домой: merge → GGUF → Modelfile → `ollama create`.
- Проводить приёмку: стиль на отложенных вопросах + общие навыки без протечек.

- **Локально:** Ollama с `qwen2.5:3b` (модули 1/5), Python 3.13, `httpx`.
  GPU не нужен.
- **Для обучения:** Google-аккаунт → [colab.research.google.com](https://colab.research.google.com),

## Как проходить

1. **Урок 1** — целиком локально (живые эксперименты с Ollama).
2. **Урок 2** — локальная часть готовит `data/train_messages.jsonl` и
   `data/val_messages.jsonl`; затем загрузите `colab-train-lora.ipynb` на Colab
   (Среда выполнения → T4 GPU), запустите по порядку, скачайте артефакты.
3. Положите артефакты в `artifacts/`:
   - `pingvin-q4_k_m.gguf` — модель со вшитым стилем (если скачали файл из Colab
     руками, он может называться по базовой модели, например
     `Qwen2.5-3B-Instruct.Q4_K_M.gguf` — просто переименуйте);
   - `pingvin-lora.zip` — адаптер (страховочная копия).
4. **Урок 3** — работает и без артефактов (прототип на SYSTEM живой), а с ними
   оживают импорт GGUF и полная приёмка.
5. **Урок 4** — финальная таблица всех подходов (колонка LoRA тоже оживает
   с артефактами), сводный квиз и практика.

> Честное примечание: `colab-train-lora.ipynb` написан по документации unsloth/trl;
> эти библиотеки быстро развиваются, и имена аргументов могут дрейфовать.
> В конце ноутбука есть раздел «Если сломалось» с планом действий.

## Практика урока 6.4: эталоны в проекте

Финальная практика остаётся вашим проектом, но эталонные решения заданий 2 и 3
лежат рядом — сверяйтесь после своей попытки:

- **Задание 2, протечка стиля:** `data/counter_examples.jsonl` (10 обычных ответов
  без якорей), `python scripts/build_dataset.py --with-counter` (пересборка train/val
  с проверкой якорей), `python scripts/acceptance.py <модель>` (стиль ≥ 28/30 и
  протечка 0 → PASS).
- **Задание 3, капстоун:** `capstone/json_bot/` — JSON-бот от датасета на 865 примеров
  до приёмки и выдачи через `ollama-proxy` (см. README внутри).
- Colab-ноутбук общий: переключатель `TASK = "pingvin" | "json"` в ШАГЕ 2.

## FAQ

**Нужен ли свой GPU?** Нет. Расчёты и приёмка — на CPU + Ollama, обучение — на
бесплатном Colab. Если свой GPU есть (от 8 ГБ VRAM), Colab-ноутбук запустится
и локально — понадобится `pip install unsloth` и скачивание базовой модели (~2 ГБ).

**Сколько стоит обучение?** Ноль: 15 шагов на 45 примерах укладываются в бесплатный
лимит Colab с огромным запасом.

**Почему «Пингвин.Хост», а не «Векторика»?** Специально другая компания: у «Векторики»
задача про **знания** (RAG, модули 2–4), у «Пингвин.Хост» — про **форму** (fine-tuning).
Разные задачи — разные инструменты; в этом половина смысла модуля.

**Можно ли пройти модуль без Colab?** Уроки 1 и 3 — почти целиком (прототип на
SYSTEM живой). Урок 2 без Colab останется теорией: адаптер сам себя не обучит.
